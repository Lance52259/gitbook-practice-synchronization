# Skills

本目录存放 gitbook-practice-synchronization 用于驱动 DeepSeek 生成文档的 Skill。

| Skill ID | 说明 |
|----------|------|
| `best-practice-doc` | 默认：对接 [hcbp-demo](https://github.com/Lance52259/hcbp-demo) 中文最佳实践文档体系 |

通过环境变量 `SKILL_ID` 或配置 `skill.id` 选择。

源脚本根目录通常为：https://github.com/huaweicloud/terraform-provider-huaweicloud/tree/master/examples
